## 🌐 Deploy

### Vercel
1. Push ke GitHub
2. Import repo di [vercel.com](https://vercel.com)
3. Deploy otomatis!

### GitHub Pages
1. Buka Settings > Pages
2. Pilih branch `main` dan folder `/ (root)`
3. Save
